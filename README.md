# Book Catalog Theme

Кастомная тема для WordPress — каталог книг с поддержкой кастомных таксономий и полей ACF.

## Требования
* **WordPress** 6.0+
* Плагин **Advanced Custom Fields (ACF)** (бесплатная или PRO версия)

---

## Установка темы

### 1. Скачивание темы
Клонируйте репозиторий в директорию тем вашего сайта:
```bash
cd wp-content/themes/
git clone git@github.com:malinainsugar/book-catalog.git book-catalog-theme
```
(Или скачайте ZIP-архив и распакуйте его в wp-content/themes/book-catalog-theme/).

### 2. Активация

1) В админ-панели WordPress перейдите в Внешний вид → Темы (Appearance → Themes).
2) Активируйте тему Book Catalog Theme.
3) Перейдите в Настройки → Постоянные ссылки (Settings → Permalinks) и нажмите «Сохранить изменения», чтобы обновились правила URL для записей книг и архивов.

### 3. Настройка ACF (Поля книги)

Для корректного отображения информации о книгах установите и активируйте плагин Advanced Custom Fields.

Создайте группу полей с условием отображения: Тип записи равно Книга (books) и добавьте поля:

| Метка поля  | Имя поля (slug) | Тип   |
|-------------|-----------------|-------|
| Автор       | author          | Текст |
| Год издания | year            | Число |
| Рейтинг     | rating          | Число |

(Если в репозитории присутствует папка acf-json, поля синхронизируются автоматически в разделе ACF → Инструменты / Группы полей).

### Особенности структуры

Тип записей: books (Книги) — регистрируется автоматически через functions.php.

Таксономия: genre (Жанры) — древовидная таксономия для книг.

Поддержка миниатюр: включена (post-thumbnails).

Меню: область header_menu (Header Menu).
